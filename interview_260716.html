MIDDLE SCHOOL DIGITAL STRATEGY

중등 현장 줌 인터뷰 요약

중등 회원관리 실태와 현장 요구를 바탕으로 도출한 디지털 상품 개발 방향 및 우선 추진 과제

작성일 2026. 7. 16.목적 중등 상품·서비스 기획 참고대상 내부 공유 및 의사결정

1. 핵심 결론

이번 인터뷰에서 가장 분명하게 확인된 것은 중등 문제의 핵심이 단순한 교재 노후화가 아니라, 중등 회원을 실제로 관리할 수 있는 운영 시스템의 부재라는 점이다.

현장에서는 윤선생 교재만으로 중등 수업을 운영하기 어려워 단어·구문·문법·내신 대비 영역에서 외부 교재와 서비스를 병행하고 있었다. 특히 중하위권 학생은 기존의 듣고 따라 말하는 자기주도형 학습이 원활하게 작동하지 않아, 교사가 지문 읽기·해석·문법 설명·단어 암기까지 다시 지도하고 있었다.

수준별 어휘·구문·문법·독해 학습 → 숙제 배정 → 자동 채점 → 오답 클리닉 → 학습 이력과 리포트 → 교사 관리

현장이 원하는 것은 새 교재 한두 종보다 위 기능이 연결된 중등 통합 관리 시스템이다. 다만 디지털 활용도가 높은 교습소와 종이 기반 밀착지도를 선호하는 학원은 요구가 뚜렷하게 달랐다. 따라서 하나의 학습 방식으로 통일하기보다 디지털 학습형과 교사 수업형을 함께 지원하는 이중 구조가 필요하다.

2. 인터뷰 목적과 현장 분위기

이번 인터뷰는 과거부터 반복된 중등 교재 VOC를 다시 듣는 데 그치지 않고, 현재 현장에서 반복적으로 수행하는 업무와 AI 활용 사례를 파악하여 현실적으로 구현 가능한 중등 상품 아이템을 찾기 위한 자리로 진행되었다.

  • 중등 교재 개선 요구가 수년간 반복되었지만 눈에 띄는 변화가 없었다는 실망감이 큼
  • 현장 원장의 피로와 소진이 심각함
  • 본사에 의견을 전달해도 달라지지 않는다는 불신이 누적됨
  • 중등 상품에 대한 자신감 저하로 홍보와 특강 운영 의욕까지 감소함
  • 윤선생이 중등을 계속할 것인지 방향을 명확히 해야 한다는 요구가 제기됨

즉, 상품 문제뿐 아니라 현장 신뢰 회복과 중등 사업 방향 제시가 동시에 필요한 상황이다.

3. 현재 중등 회원관리 방식

영역실제 운영 방식
어휘교과서 단어와 학생 수준별 외부 단어장을 병행하고 누적 시험 실시
구문짧은 문장을 직독직해·어순 배열·암기 방식으로 반복
문법외부 문법 문제집과 구문 학습을 결합해 지도
독해윤선생 Reading Solutions·Reading Focus를 활용하되 교사가 다시 읽고 해석 확인

중학생 신규 회원은 자기주도학습 습관이 거의 형성되지 않은 경우가 많아, 음원을 듣고 따라 읽게 하는 기존 방식만으로는 수업이 진행되지 않았다.

  1. 본문 처음부터 다시 읽기
  2. 문장별 해석 확인
  3. 주요 구문과 문법 설명
  4. 단어 암기 여부 확인
  5. 관련 문제 풀이
  6. 학교 내신 및 수행평가 연결

결국 기존 시스템이 자동화해 주지 못하는 부분을 교사가 직접 메우고 있었다.

4. 원장별 운영 유형

A. 디지털 적극 활용형

  • 클래스카드로 단어·구문 숙제 배정 및 이행 여부 확인
  • 교과 단어와 학생별 수준 단어를 별도로 운영
  • 천일문·천문장·문장해석 트레이닝 등 외부 구문 교재 활용
  • Claude·ChatGPT 등을 활용해 외부 지문 수정 및 문제 생성
  • 학생별 과제와 피드백을 디지털로 누적 관리
  • 종이 출력보다 온라인 과제·자동 채점·학습 이력 관리를 선호

핵심 요구: 클래스카드에 지불하는 비용을 윤선생 시스템에 지불할 수 있도록 유사 기능을 제공해 달라는 요구

B. 아날로그 밀착지도형

  • 학생과 교사가 함께 단어를 외우고 문제를 풂
  • 휴대전화를 수거하고 수업에 집중시키는 운영
  • 리딩 교재를 활용하되 읽기와 해석은 교사가 직접 확인
  • 외부 어휘·문법 교재를 다수 병행
  • 자체 제작 시험지로 누적 단어 시험 운영
  • 자동화보다 충분한 문제와 종이 워크시트, 교사용 자료를 선호

핵심 우려: 학생용 AI 활동이 늘어날수록 오히려 교사가 관리해야 할 화면과 업무가 증가할 가능성

5. 영역별 핵심 문제와 요구

5-1. 어휘

어휘는 현장에서 가장 기본적이고 시급한 영역으로 제시되었다.

  • 학생별 수준 차이가 매우 커 학년 단위 단어장으로 관리하기 어려움
  • 교과서 단어와 일반 어휘를 따로 관리해야 함
  • 기존 윤선생 어휘 콘텐츠만으로 중등·고등까지 연결하기 어려움
  • 시험지 제작, 누적 시험, 숙제 확인을 현장에서 직접 처리
  • 외부 단어장과 클래스카드 의존도가 높음

필요 기능

수준별 어휘 체계학생별 단어 배정교사 직접 입력·업로드자동 음성·뜻·철자누적 복습취약 단어 클리닉교사·학부모 리포트

판단: 우선순위가 가장 높은 MVP 영역으로 판단된다.

5-2. 문법

현장에서는 오래된 문법 교재의 디자인과 체계도 문제로 보았지만, 새 종이책보다 문법 개념 학습과 드릴을 디지털로 연결하는 구조를 더 중요하게 평가했다.

  • 기존 Grammar Bot은 학년·수준별 문제 생성 기능은 장점
  • 문제 출력에서 끝나 실제 운영 효율이 낮음
  • 개념 설명이 부족함
  • 출력·배부·채점·오답 관리가 다시 교사 업무로 남음
짧은 개념 설명 → 예문·구문 패턴 학습 → 단계별 드릴 → 자동 채점 → 취약 문법 재학습

같은 학년에서도 be동사·일반동사를 반복해야 하는 학생과 가정법·분사를 학습하는 학생이 함께 존재하므로, 학년별이 아니라 진단 기반의 세분화된 레벨 구조가 필요하다.

5-3. 구문

문법을 바로 설명하기보다 구문을 먼저 반복시키고, 문장이 익숙해진 뒤 문법 개념을 연결하는 방식이 효과적이라는 의견이 제시되었다.

  • 의미 단위 끊어 읽기
  • 직독직해
  • 어순 배열
  • 핵심 문장 암기
  • 문장 해석
  • 패턴 변형
  • 관련 문법 개념 연결

기존 Pattern English는 방향은 적절하지만 내용이 충분히 촘촘하지 않다는 평가가 있었다.

5-4. 독해

Reading Solutions와 Reading Focus A는 비교적 긍정적으로 평가되었다. 한 지문을 예습·본문·어휘·핵심 문장·구문으로 후처리하는 구조의 활용도가 높았다.

  • 후속 레벨 B·C 부족
  • 음원과 설명이 지나치게 길고 오래된 느낌
  • 학생이 듣기만 하고 실제 내용을 이해했는지 확인하기 어려움
  • 한 지문당 문제 수가 적어 깊이 있는 학습이 어려움
  • 교재 완권 테스트가 오래되고 현행 평가와 맞지 않음
  • 일부 고난도·구형 리딩 시리즈는 활용도가 거의 없음

현장이 요구한 깊이 학습형 독해

주제·요지세부 정보빈칸·어휘·문법문장 배열서술형요약핵심 구문수능형 문항

6. 내신·특강 운영 문제

학교 내신 대비 기간에는 윤선생 정규 학습 비중이 크게 줄고, 시중 교재를 2~3권씩 사용하는 것이 일반적이었다.

  • 윤선생 교재만으로는 학교별 내신 대비가 어려움
  • 특강에서 외부 교재 사용을 제한하면 실제 운영이 불가능함
  • 평소 사용하던 동일한 윤선생 교재로 방학 특강을 홍보하기 어려움
  • 교과서별 지원에는 한계가 있지만 공통 지원 도구도 부족함

현실적인 지원 방향

  • 교사가 보유한 교과서·학교 자료 업로드
  • 텍스트 추출 및 정리
  • 단어·문장·문법 포인트 자동 분류
  • 유사 문제·서술형·어순 배열 자동 생성
  • 학생별 과제 배정
  • 자동 또는 반자동 채점
  • 학교별 자료 저장 및 재사용

7. 숙제와 관리 기능 요구

숙제는 중등 회원관리에서 필수였지만 현재는 외부 시스템이나 수기 관리에 의존하고 있었다. 현장이 원하는 핵심은 새로운 활동의 수보다 숙제를 한 번에 배정하고 수행 여부를 바로 확인하는 기능이었다.

주요 숙제필수 관리 항목
교과 단어 및 수준별 단어과제 배정일·마감일, 완료 여부, 점수, 재도전 이력
구문 암기·문장 해석·어순 배열학습 시간, 미완료 학생 목록, 오답·취약 영역
딕테이션·문법 문제집·본문 쓰기교사 코멘트, 학부모 상담용 요약, 주간 리포트

8. 디지털 상품 설계 시 주의점

8-1. 하나의 방식으로 통일하면 실패 가능성이 높음

디지털 활용형 현장아날로그 밀착형 현장
숙제·채점·이력 자동화를 원함학생 화면 사용을 신뢰하기 어려움
클래스카드 대체 시스템 요구종이 교재와 워크시트 선호
학생의 가정 학습까지 연결 희망센터 안에서 교사가 직접 관리
관리자 대시보드 중요교사용 출력 자료와 정답지 중요

동일한 콘텐츠를 교사가 상황에 따라 다음 방식으로 선택할 수 있어야 한다.

학생 온라인 학습교사용 화면 수업종이 워크시트 출력온라인 자동 채점교사 직접 채점온라인 숙제센터 내 오프라인 수업

8-2. AI 기능이 교사 업무를 늘려서는 안 됨

현장 관점에서 AI의 가치는 화려한 학생 활동이 아니라 다음 업무를 줄이는 데 있다.

  • 시험지 제작 시간 절감
  • 채점 자동화
  • 학생별 과제 분기
  • 취약 영역 분석
  • 피드백 초안 생성
  • 상담 리포트 작성
  • 반복 행정업무 감소

9. 사업 및 브랜드 시사점

9-1. 중등의 타깃 고객을 명확히 해야 함

현장에서는 최상위권 진학 사례보다, 영어를 포기할 가능성이 높은 중하위권 학생을 실제로 성장시키는 브랜드가 윤선생의 현실적인 강점이 될 수 있다는 의견이 나왔다.

영어를 포기하지 않게 하고, 단어·문장·독해의 기본기를 실제로 쌓아 주는 중등 관리 시스템

9-2. 브랜드와 상품 체계가 지나치게 복잡함

  • 현재 중등 교재·서비스 사용률 조사
  • 유지·개편·폐지 분류
  • 유효 콘텐츠만 현대적으로 재가공
  • 핵심 중등 상품군을 소수로 단순화
  • 브랜드별 역할과 고객을 명확히 구분

9-3. 유료화 가능성은 있음

현장에서는 클래스카드와 외부 교재에 이미 비용을 지출하고 있었다. 따라서 단어·문법·숙제·채점·리포트 기능이 통합된다면 기존 교재비 또는 별도 사용료 형태로 과금할 가능성이 있다.

콘텐츠 + 과제 + 채점 + 클리닉 + 관리 + 리포트

10. 우선 추진 제안

1

중등 어휘·숙제 관리 MVP

가장 공통적이고 사용 빈도가 높으며 외부 유료 서비스 대체 가능성이 명확한 영역

  • 수준별 어휘 DB
  • 교사 직접 단어 입력
  • 학생별 숙제 배정
  • 자동 테스트와 누적 복습
  • 미완료·취약 단어 확인
  • 주간 리포트
  • 온라인·출력형 동시 지원
2

문법 개념·드릴·자동 채점

Grammar Bot을 단순 출력 도구에서 실제 학습 시스템으로 확장

  • 예문과 구문
  • 단계별 문제
  • 자동 채점
  • 오답 재학습
